# The Smile Initiative

A simple website for The Smile Initiative, a community project that brings oral health education to kids at local libraries and community centers.

[Visit the website](https://the-smile-initiative.zanybat32.chatgpt.site)

## About the site

The website includes our mission, story, team, an education page for upcoming blog posts, and ways to volunteer or partner with us.

Built with plain HTML and CSS. No dependencies or build step required.

## Preview

```sh
python3 -m http.server 8080 --directory site/dist
```

Open http://localhost:8080. Edit `site/dist/index.html`, `site/dist/education.html`, and `site/dist/styles.css`. Photos are in `site/dist/assets/`.

The Education page is ready for future blog posts; no posts have been supplied yet.
